IBAD3 PRO - الموقع الأولي

1) افتح Firebase Console وأنشئ مشروعًا.
2) فعّل Authentication > Sign-in method:
   - Email/Password
   - Google
3) أنشئ Firestore Database.
4) انسخ Firebase Web App config إلى app.js بدل YOUR_...
5) طبّق قواعد firebase.rules.txt على Firestore.
6) استبدل رقم WhatsApp في index.html والرابط والبريد hello@ibad3pro.com ببياناتكم.
7) شغّل الموقع عبر استضافة تدعم HTTPS (Firebase Hosting / Vercel / Netlify).

الموقع يدعم:
- العربية RTL
- Responsive للهاتف والكمبيوتر
- أقسام الخدمات والأعمال ومن نحن وطريقة العمل
- نموذج طلب خدمة
- تسجيل Email/Password
- تسجيل Google
- حفظ طلبات العملاء في Firestore
- فلترة معرض الأعمال
